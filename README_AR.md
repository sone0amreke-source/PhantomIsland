# Phantom Island — النسخة الأصلية 0.1

هذا مشروع Android أصلي بلغة Java، وليس صفحة HTML فقط. يتضمن نموذج جزيرة عائمة قابلة للفتح والإغلاق والسحب، مع لوحة تجريبية.

## البناء من الجوال عبر GitHub Actions
1. أنشئ مستودعًا جديدًا في GitHub باسم `PhantomIsland`.
2. ارفع محتويات هذا المجلد إلى المستودع مع الحفاظ على مجلد `.github/workflows`.
3. افتح تبويب **Actions** واسمح بتشغيل workflows إذا طلب منك.
4. شغّل **Build Phantom Island APK** من زر **Run workflow**.
5. بعد نجاح التشغيل، افتح نتيجة التشغيل ونزّل artifact باسم `Phantom-Island-debug-APK` ثم فك ضغطه لتحصل على APK.

## الصلاحيات
- صلاحية الظهور فوق التطبيقات: لازمة للجزيرة العائمة، ويجب أن يوافق عليها المستخدم يدويًا من إعدادات أندرويد.
- إشعار دائم: يعرضه أندرويد لأن التطبيق يستخدم خدمة أمامية لإبقاء الجزيرة ظاهرة.
- لا توجد صلاحيات لجهات الاتصال أو الرسائل أو الحسابات أو الإنترنت أو الموقع.

## ما هو تجريبي حاليًا؟
الموسيقى ولوحة Pulse واجهة تجريبية ولا تتصل بمشغل الموسيقى الحقيقي بعد. لا توجد قراءة للإشعارات الحقيقية بعد. هذا إصدار أولي غير مختبر على الجهاز الفعلي؛ يجب اختبار البناء وتثبيته قبل إضافة مزايا أخرى.
